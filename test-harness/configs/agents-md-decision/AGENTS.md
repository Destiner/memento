# Project notes

## Memory (memento)

Before starting a task, ask: could part of this already be settled — a past
decision, a known constraint, a lesson learned? If it might be, run one
targeted memento `search_memory` first and read the top result before choosing
an approach. Treat code and current repository docs as more authoritative than
memory. After finishing, if the work surfaced a durable insight that will
matter beyond this task, save it with `create_memory`; never record routine
status.
